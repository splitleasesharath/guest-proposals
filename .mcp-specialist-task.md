# MCP Specialist Task: Supabase Database Photo Structure Query

## Context
User needs to understand the structure of listing photos in the Supabase database to implement featured photo display on the guest proposals page.

## Objectives
1. List all tables in the database to identify the photos/images table
2. Query the photos table structure to understand schema and fields
3. Identify the field that indicates a "featured photo" or "toggle photo to yes"
4. Understand the relationship between listings and photos tables (foreign keys, etc.)

## Goal
Display the featured photo (where toggle photo = yes) for a listing in the guest proposals page.

## Required Actions
1. Use `mcp__supabase__list_tables` to get all tables
2. Use `mcp__supabase__execute_sql` to:
   - Examine the photos/images table schema
   - Query sample data to understand the structure
   - Identify the field for featured/toggled photos
   - Find the foreign key relationship to listings

## Expected Deliverables
- Complete list of database tables
- Schema details for the photos table
- Sample photo records showing field names and values
- Identification of the "featured photo" indicator field
- Documentation of the listings-to-photos relationship

## Additional Context
This is for the guest proposals page where each proposal needs to display the associated listing's featured photo.
